An entry for make.fun's [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty: one joke pickup line, under 200 characters, aimed at a robot or an AI — the context window itself is the compliment, and everything that is not you falls out of memory.

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644.
